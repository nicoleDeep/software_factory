# IMP-0001 首项目试运行测量工具

## 观察与根因

- 来源：v0.1.0 基线自身（尚无真实项目）。已记录的未验证项：10 节点/5 门禁的轻量性假设未测、任务模板的恢复作用未测、证据字段充分性未知、项目级 Skill 的现场发现未验证。
- 根因分类：流程缺陷——缺少测量工具，首个项目结束后将无法用数据裁决架构与流程问题，自进化闭环的第一步（观察→提案）没有数据来源。

## 变更

- 新增 `factory/first-project-trial.md`：把改进闭环中列出的 v0.1 假设转为可测量清单（H1–H6），含 Skill 现场发现步骤与成本基线表。
- APP 产线版本 0.1.0 → 0.1.1（PATCH：新增文档与导航链接，不改变任何节点、门禁、DoR/DoD 或放行义务）。
- 同步 VERSION、pipeline.json、产线注册表、CHANGELOG、相关文档版本标注与导航链接。

## 评测

- 结构验证：`scripts/validate.py` 与 `python3 -m unittest discover -s tests -v` 在发布前实际执行，结果见对应提交（结构契约保持绿色）。
- 现场收益：**未验证**——待首个真实项目按试运行清单填写数据后裁决。本提案不声称任何交付效率收益。

## 决定

- 决定：released（PATCH 级，不触及验收、安全、权限、发布义务）。
- 授权依据：用户会话目标（构建可自进化软件工厂）下的持续推进授权；PATCH 级变更按 v0.1.0 版本约定可由维护者实施。用户可否决或回退。
- 回滚：revert 本提交即可，无数据迁移、无在途项目兼容负担（0.1.0 项目仅引用文档，无义务变化）。
