# 模板索引

模板是空白表单，不是完成证据。复制到目标项目后填写实际值；无法确定写“待确认”，并记录负责人。项目副本中的路径需要按实际位置重写。

| 模板 | 使用时机 | 建议保存位置 |
|---|---|---|
| [项目运行档案](<project-run.md>) | APP-01 启动，后续持续更新 | 产品仓库项目文档区 |
| [任务包](<task.md>) | APP-05 起，每个可验证任务一份 | 产品仓库任务文档区 |
| [门禁记录](<gate-review.md>) | G1–G5，每次决定独立留档 | 产品仓库验收记录区 |
| [发布包](<release.md>) | APP-08/09，发布前后更新 | 产品仓库发布记录区 |
| [工厂改进提案](<improvement.md>) | 遇到产线问题 | 本仓库 improvements 或敏感项目内 |
| [候选经验](<lesson.md>) | 修复、里程碑、复盘 | 本仓库 00-Inbox 或敏感项目内 |

架构图、界面设计、测试报告可以来自外部工具，但需要稳定引用、版本和访问说明。大文件、密钥和客户原始数据不直接放入共享工厂仓库。
